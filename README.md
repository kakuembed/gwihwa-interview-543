# 귀화면접 543

대한민국 귀화(사회통합프로그램) 면접 예상문답 543문항을 학습/시험/오답노트로 연습하는 웹앱.

**라이브 주소:** https://kakuembed.github.io/gwihwa-interview-543/
(로그인 불필요. 아이폰 Safari → 공유 → "홈 화면에 추가"로 앱처럼 설치 가능)

## 이 프로젝트가 만들어진 과정

1. 원본은 베트남어 챕터 표기가 섞인 한국 귀화면접 예상문답 mp3 9개 (약 3시간 분량).
2. 로컬 Whisper(medium 모델, faster-whisper)로 전체 음성 인식 → 타임스탬프 포함 개별 챕터 텍스트 생성.
3. 하나의 마스터 텍스트로 통합 후, 오타/오인식 300개 이상을 여러 차례 정밀 교정 (역사·법률·행정 용어, 고유명사, 인명 등). 애매한 답변 5개는 원본 오디오를 재추출해 고정확도(beam_size=5)로 재확인.
4. 정규식 기반 파서로 543개의 (번호, 질문, 답변) 쌍을 자동 추출 → 질문/답 경계가 꼬이는 버그(예: "~까지"의 "까"를 물음표로 오인)를 여러 차례 발견해 수정. 이후 543개 전체를 수작업으로 다시 검수.
5. 결과를 하나의 자기완결형 `index.html`에 인라인으로 삽입 (외부 데이터 파일 의존성 없음 — 모바일 환경에서 별도 파일 로딩 실패 이슈가 있었어서 전부 합침).
6. GitHub Pages로 배포 (로그인 없이 누구나 접속 가능한 정적 사이트).

## 기능

- **학습 모드**: 카드 뒤집기 방식. 탭하면 정답 → 한 번 더 탭하면 다음 문제. 섹션별 진행률 표시, 목차에서 번호로 바로 이동 가능. 마지막 위치 자동 저장(기기별 localStorage).
- **시험 모드**: 질문을 보고 정답을 직접 타이핑 → 채점. 공백/문장부호/"~입니다" 등 어미 차이는 무시하는 정규화 채점. 자동 채점이 애매하면 "정답으로 표시"/"오답으로 표시" 버튼으로 수동 override 가능.
- **오답노트**: 시험 모드에서 틀린 문제만 모아보기 (내가 쓴 답 vs 정답), "다시 풀기"로 바로 재도전, 전체 삭제 가능.
- **설정(⚙) — 테마**: 핑크(기본) / 그린(화이트 배경 + 연녹색, 눈에 편한 톤) 중 선택. 라이트/다크 모드 자동 대응. 선택은 기기별로 저장.

## 저장소 구조

```
index.html          ← 배포되는 파일 전체 (543문항 데이터 인라인 포함, 외부 의존성 없음)
source/
  귀화면접_전체정리.txt  ← 교정 완료된 마스터 텍스트 (타임스탬프 제거, 챕터 구분)
  parse_qa.py          ← 마스터 텍스트 → (번호,질문,답변) JSON 파서
```

## 업데이트 방법 (다음 대화에서 이어갈 때)

1. `C:\Users\hardw\maistudy\gwihwa-web\index.html` 을 직접 수정 (또는 `source/` 자료를 고쳐서 `parse_qa.py` 재실행 후 결과를 index.html의 `QA_DATA`/`SECTIONS` 상수에 다시 삽입).
2. 로컬에서 확인: `python -m http.server 8000` 으로 `index.html`을 서빙해서 브라우저로 점검 (data URL 스냅샷 문제를 피하려면 반드시 http 서버를 거칠 것).
3. `git add -A && git commit -m "..." && git push origin master` — 그러면 GitHub Pages가 자동으로 재배포됨 (보통 30~60초 소요).
   - **주의**: push 전에 항상 `git fetch && git log origin/master` 로 원격에 로컬에 없는 커밋이 있는지 확인할 것. 사용자가 GitHub 웹 UI에서 직접 `<title>`을 "YEU MAI QUA"로 수정한 적이 있음 (커밋 `e1809c0`, `0b0e373`) — 이런 수동 수정을 덮어쓰지 않도록 항상 merge할 것.
4. 버전을 남기고 싶으면 `git tag -a vX.Y -m "..."; git push origin vX.Y` 및 `gh release create vX.Y ...`.

## 알려진 남은 이슈 / 참고사항

- 원본 오디오 자체에 답이 누락된 문항 5개는 문맥상 추정하여 채워 넣음 (346번 "가족관계증명서"는 특히 불확실 — 카드에 "⚠ 추정 답변" 배지 표시됨). 8, 102, 526, 527번은 확실.
- 원본 문항 번호 중 14, 106, 308, 312번은 원본 음성 자체에서 건너뛰어 존재하지 않음 (정상, 버그 아님). 총 543개 카드 = 547 - 4.
- 네이티브 앱(Flutter/iOS) 빌드는 시도하지 않음 — iOS는 Mac+Xcode(+개발자 계정) 필요, 이 작업환경은 Windows라 웹앱(GitHub Pages) 방식으로 대체함.
- GitHub 계정: `kakuembed` (저장소 소유자, gh CLI 인증 완료 상태였음 — 새 대화/새 환경에서는 재인증 필요할 수 있음: `gh auth login`).
